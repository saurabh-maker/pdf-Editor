How to use: click any text to edit it · drag the blue ✥ handle next to a line to move it · whiteout boxes can be dragged too · use the buttons above each page to move, add or delete pages · Ctrl+Z undoes page changes

Edit text in any PDF

Drop a PDF here or choose one. Click any line of text to change it; layout, spacing and everything else stay exactly where they are. Everything runs in your browser; the file is never uploaded.

Works on text-based PDFs (not scans). Enter finishes a line, Esc undoes it.
